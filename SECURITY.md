# Security Policy

## Supported versions

Security fixes are provided for the latest published `photo_gallery_gdx_plus` release. Users should upgrade to the newest available version before reporting an issue.

The upstream `photo_gallery` package and older releases under that name are not maintained by this repository.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Report it privately to `contact@gurwinderdevx.com` with:

- the affected version and platform;
- a clear description of the impact;
- reproduction steps or a proof of concept;
- any suggested mitigation; and
- whether the report is subject to a disclosure deadline.

Please avoid accessing data that is not yours, disrupting services, or publishing details before a fix can be assessed. You should receive an acknowledgement within seven days. After validation, the maintainer will coordinate remediation and responsible disclosure.

For non-security bugs, use the public [issue tracker](https://github.com/47gurvinder/photo_gallery/issues).
